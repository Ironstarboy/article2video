# InfiniteTalk 启动文档（小白版）

> 这份文档只讲**怎么启动**。照着复制粘贴命令就能跑起来。
>
> ✅ 本项目已在 **PPU-ZW810E** 上验证跑通（2026-09-10）。

---

## 🚀 三步启动

### 第一步：打开终端

在 DSW 里打开一个终端（Terminal）。

### 第二步：复制粘贴这一整段，回车

```bash
source /usr/local/PPU_SDK/envsetup.sh
cd /mnt/workspace/ttv/InfiniteTalk/code
```

> ⚠️ **第一行绝对不能漏！** 这是 PPU 加速卡的环境配置，不执行会导致 `CUDA 不可用`。

### 第三步：启动 Web 界面（推荐）

```bash
CUDA_VISIBLE_DEVICES=1 /mnt/workspace/ttv/InfiniteTalk/env/bin/python app.py \
    --ckpt_dir ../weights/Wan2.1-I2V-14B-480P \
    --wav2vec_dir ../weights/chinese-wav2vec2-base \
    --quant fp8 \
    --quant_dir ../weights/InfiniteTalk-fp8/quant_models/infinitetalk_single_fp8.safetensors
```

启动过程约 1-3 分钟（加载模型）。看到下面这行就成功了：

```
Running on local URL:  http://0.0.0.0:8418
```

然后在浏览器打开 **`http://127.0.0.1:8418`**，或在 DSW 服务访问里点开端口 **8418**。

---

## ⚠️ 关于显卡（重要）

这台机器有 4 张卡，其中 **GPU 0 是给 ComfyUI 用的（占着 90GB）**，不要碰。

启动前用 `CUDA_VISIBLE_DEVICES` 指定空闲的卡：

| 值 | 说明 |
|----|------|
| `CUDA_VISIBLE_DEVICES=1` | 用第 2 张卡（**推荐**） |
| `CUDA_VISIBLE_DEVICES=2` | 用第 3 张卡 |
| `CUDA_VISIBLE_DEVICES=3` | 用第 4 张卡 |

查看各卡占用：

```bash
/usr/local/PPU_SDK/ppu-smi/bin/ppu-smi
```

## 🖥️ 网页界面怎么用

打开网页后：

1. **上传图片或视频** —— 一张人物照片，或一段人说话的视频
2. **上传音频** —— 要配音的音频（wav 格式）
3. **填写提示词**（可选）—— 描述画面内容
4. **点生成按钮** —— 等待出结果

> 生成一个视频通常需要几分钟，取决于音频长度和分辨率。

## 💻 命令行方式（不用网页）

```bash
# 每次新开终端都要先跑这两行
source /usr/local/PPU_SDK/envsetup.sh
cd /mnt/workspace/ttv/InfiniteTalk/code

# 跑官方示例（图片 + 音频 → 说话视频）
CUDA_VISIBLE_DEVICES=1 /mnt/workspace/ttv/InfiniteTalk/env/bin/python generate_infinitetalk.py \
    --ckpt_dir ../weights/Wan2.1-I2V-14B-480P \
    --wav2vec_dir ../weights/chinese-wav2vec2-base \
    --quant fp8 \
    --quant_dir ../weights/InfiniteTalk-fp8/quant_models/infinitetalk_single_fp8.safetensors \
    --input_json examples/single_example_image.json \
    --size infinitetalk-480 \
    --sample_steps 40 \
    --mode streaming \
    --motion_frame 9 \
    --save_file 我的视频
```

**结果在哪？** 生成完成后，会在当前目录生成 `我的视频.mp4`。

## 📝 换成自己的素材

### 准备两个文件

| 文件 | 说明 | 格式 |
|------|------|------|
| 人物图片/视频 | 要让它说话的人 | `.png` / `.jpg` / `.mp4` |
| 音频 | 要配的声音 | `.wav` |

### 建一个自己的 json 文件

在 `InfiniteTalk-main/` 目录下新建 `我的输入.json`：

```json
{
  "prompt": "一位女士正在对着麦克风说话",
  "cond_video": "/绝对路径/人物图片.png",
  "cond_audio": {
    "person1": "/绝对路径/音频.wav"
  }
}
```

> 💡 路径建议写**绝对路径**，不容易出错。

### 用自己文件跑

把上面命令里的 `--input_json examples/single_example_image.json` 换成 `--input_json 我的输入.json` 即可。

## 🎛️ 常用开关

| 参数 | 作用 | 建议 |
|------|------|------|
| `--size infinitetalk-480` | 480P 分辨率 | 快 |
| `--size infinitetalk-720` | 720P 分辨率 | 清晰但慢约 3 倍 |
| `--sample_steps 40` | 采样步数 | 40 够用，调小更快 |
| `--mode streaming` | 长视频模式 | 长音频用 streaming |
| `--motion_frame 9` | 动作幅度 | 默认 9 |

## ❓ 遇到问题

### 报错 `CUDA 不可用` / `torch.cuda.is_available() = False`

忘了执行第一步。补上：

```bash
source /usr/local/PPU_SDK/envsetup.sh
```

### 报错 `No module named xxx`

用错 python 了。必须用完整路径 `/mnt/workspace/ttv/InfiniteTalk/env/bin/python`，不要用 `python`。

### 报错 `ImportError: cannot import name 'ArgSpec'`

项目源码的 Python 3.12 兼容问题，**已修复**。如果重新 clone 了代码需重新修复：
把 `wan/multitalk.py` 第 3 行的 `from inspect import ArgSpec` 删掉。

### 显存不足 / OOM

在命令里加一行 `--num_persistent_param_in_dit 0`。

### 网页打不开

1. 确认终端没关、进程还在跑
2. 确认用的是 `http://127.0.0.1:8418`
3. 检查端口：`ss -tlnp | grep 8418`

### 想看运行日志

启动命令末尾加 `2>&1 | tee run.log`，日志会同时写到 `run.log`。
