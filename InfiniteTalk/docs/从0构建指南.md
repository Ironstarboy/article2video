# InfiniteTalk on PPU-ZW810E —— 从 0 构建指南

> 本文档记录在 **T-HEAD PPU-ZW810E** 加速卡上从零构建 InfiniteTalk 运行环境的**完整可用流程**。
> 所有命令均已实测通过（2026-09-10，uv 0.12.5 / PPU SDK 2.1.0 / Ubuntu 24.04 / Python 3.12）。
>
> ⚠️ **先读第 1 节**。PPU 不是通用显卡，按常规 `pip install torch` 的流程**必然失败**。

---

## 1. 核心认知：PPU 不是通用 CUDA 设备

PPU（T-HEAD ZW810E）通过一层 CUDA 兼容层工作，但 **公版 PyTorch 无法驱动它**。实测对照：

| PyTorch 版本 | 来源 | 结果 |
|--------------|------|------|
| `2.4.1+cu121` | pytorch.org | ❌ `cudaGetDeviceCount` → invalid argument |
| `2.5.1+cu121` | pytorch.org | ❌ 同上 |
| `2.10.0+cu130` | pytorch.org | ❌ 同上，且与 PPU 的 libnccl/libcudart 符号冲突 |
| **`2.10.0+ppu2.1.0`** | **厂商源** | ✅ 4 卡 / 96GB 每卡 / 运算正常 |

**根因**：公版 torch 自带 pip 版 CUDA 运行时（`nvidia-*-cu13`），与 PPU 的 `libcuda.so.1` 兼容层不兼容；
PPU 自带的 `libcudart` 又缺少公版 torch 需要的符号（如 `__cudaGetKernel`）。**两者必须配套使用**。

### 1.1 三条铁律

1. **必须用厂商 PPU 版 wheels**（`+ppu2.1.0`），不能从 PyPI 装 torch
2. **每次运行前必须** `source /usr/local/PPU_SDK/envsetup.sh`
3. **必须用 Python 3.12**（厂商 torch 2.10.0 只提供 cp312）

### 1.2 厂商源地址

```
https://aiext-pypi.mirrors.aliyuncs.com/pg1-pip/generic/
```

⚠️ 这个源**没有 PEP503 simple 索引**（`/simple/` 返回 403/404），只能：
- 用浏览器/curl 浏览目录列表找到文件
- 然后给 **直链或本地路径**，不能让工具自己解析版本

浏览可用版本：

```bash
curl -s "https://aiext-pypi.mirrors.aliyuncs.com/pg1-pip/generic/torch/" \
  | grep -oE '2\.[0-9]+\.[0-9]+%2B[^/]+/' | sed 's/%2B/+/;s#/##' | sort -uV | tail -20
```

**命名规则**：`<torch版本>+<cuda>torch<torch版本><系统><oe/ce>-cp<py>-...whl`

| 片段 | 含义 |
|------|------|
| `ubuntu2404` | Ubuntu 24.04（本机） |
| `alios7u2` | 阿里云 Linux |
| `oe` / `ce` | 厂商定制后缀 |
| `cp312` | Python 3.12 |

## 6. 步骤四：源码补丁（2 处）

### 6.1 删除 Python 3.11+ 已移除的 `ArgSpec`

`wan/multitalk.py` 第 3 行 `from inspect import ArgSpec` 在 Python ≥3.11 报 `ImportError`。
该名称**未被使用**，直接删：

```bash
sed -i '/^from inspect import ArgSpec$/d' wan/multitalk.py
```

### 6.2 修复 T5 类定义层的 CUDA 调用

`wan/modules/t5.py` 中 `T5EncoderModel.__init__` 的默认参数 `device=torch.cuda.current_device()`
会在**类定义时**（import 阶段）求值，导致 CUDA 未就绪时报错。改为：

```bash
sed -i 's/        device=torch\.cuda\.current_device(),/        device=0,/' wan/modules/t5.py
```

## 7. 步骤五：安装项目依赖

本项目需要两个依赖文件：官方的 `requirements.txt` + PPU 补充文件 `requirements-ppu.txt`。

### 7.1 创建 `requirements-ppu.txt`

```bash
cat > requirements-ppu.txt << 'EOF'
# InfiniteTalk 在 PPU-ZW810E 上的补充依赖

# ---- 源码 import 了但 requirements.txt 未列出 ----
misaki[en]          # kokoro TTS 需要；必须带 [en]，否则缺 spacy/num2words
espeakng-loader     # misaki 的 espeak 后端
phonemizer
protobuf            # transformers 转换 umt5 tokenizer；缺了报 Cannot parse precompiled_charsmap
tiktoken            # protobuf 缺失时的兜底
soundfile
einops
ftfy
triton==3.6.0       # xfuser 导入链需要；必须与 torch 2.10 配套

# ---- 版本约束（关键）----
librosa<1.0         # librosa 1.0+ 强制 numpy>=2，与 requirements.txt 的 numpy<2 冲突
peft>=0.17          # diffusers 0.40 需要；旧版报 disable_input_dtype_casting 导入失败
EOF
```

### 7.2 安装

```bash

  --index-url https://mirrors.aliyun.com/pypi/simple/ \
  -r requirements.txt -r requirements-ppu.txt
```

> ⚠️ **必须显式 `--index-url`**。uv 不读 pip.conf 的清华源配置，
> 而清华源对某些工具会返回 403，容易卡住。

## 8. 步骤六：下载模型权重（约 95GB）

```bash
mkdir -p /mnt/workspace/ttv/InfiniteTalk/weights && cd /mnt/workspace/ttv/InfiniteTalk
export HF_ENDPOINT=https://hf-mirror.com
```

### 8.1 Wan2.1 基础模型（~67GB）

```bash
hf download Wan-AI/Wan2.1-I2V-14B-480P --local-dir ./weights/Wan2.1-I2V-14B-480P
```

**必须确认这 3 个文件存在**（容易漏）：

```bash
ls weights/Wan2.1-I2V-14B-480P/ | grep -E "models_clip|diffusion_pytorch_model-0000[1-7]"
# 需要：
#   diffusion_pytorch_model-00001~00007-of-00007.safetensors（7 个分片）
#   Wan2.1_VAE.pth
#   models_clip_open-clip-xlm-roberta-large-vit-huge-14.pth   ← 常漏，缺了无法启动
```

### 8.2 Tokenizer 文件（常漏！）

```bash
hf download Wan-AI/Wan2.1-I2V-14B-480P \
  google/umt5-xxl/tokenizer.json \
  xlm-roberta-large/tokenizer.json \
  xlm-roberta-large/sentencepiece.bpe.model \
  --local-dir ./weights/Wan2.1-I2V-14B-480P
```

> 缺 `tokenizer.json` 会报 `Cannot parse precompiled_charsmap`。

### 8.3 Wav2Vec2 音频编码器（~1.5GB）

```bash
hf download TencentGameMate/chinese-wav2vec2-base --local-dir ./weights/chinese-wav2vec2-base

# ⚠️ 必须额外下载 safetensors 版本（走 refs/pr/1 分支）
hf download TencentGameMate/chinese-wav2vec2-base model.safetensors \
  --revision refs/pr/1 --local-dir ./weights/chinese-wav2vec2-base
```

> 不下载 safetensors 的话，会走 `torch.load` 加载 `.bin`，
> 在 transformers 5.x + torch<2.6 组合下报 CVE-2025-32434 相关的版本限制错误。

### 8.4 InfiniteTalk 量化权重（fp8，~25GB）

```bash
hf download MeiGen-AI/InfiniteTalk \
  quant_models/infinitetalk_single_fp8.safetensors \
  quant_models/infinitetalk_single_fp8.json \
  quant_models/t5_fp8.safetensors \
  quant_models/t5_map_fp8.json \
  --local-dir ./weights/InfiniteTalk-fp8
```

> 🔴 **必须用 fp8，不能用 int8。**
> 仓库只提供 `t5_fp8.safetensors`（**没有** `t5_int8.safetensors`），
> 而代码按 `--quant` 的值拼 T5 权重文件名：`f"t5_{quant}.safetensors"`。
> 用 `--quant int8` 会因为找不到 `t5_int8.safetensors` 直接失败。

## 10. 排错速查表

| 报错 | 原因 | 解决 |
|------|------|------|
| `cudaGetDeviceCount ... invalid argument` | 装了公版 torch | 换厂商 `+ppu2.1.0` 轮子 |
| `undefined symbol: ncclAlltoAll` | 公版 torch + PPU libnccl 混用 | 同上 |
| `undefined symbol: __cudaGetKernel` | 公版 torch + PPU libcudart 混用 | 同上 |
| `CUDA: False` 但 torch 版本对 | 忘了 source 环境脚本 | `source /usr/local/PPU_SDK/envsetup.sh` |
| `Wheel version does not match filename` | uv 校验厂商轮子 | `UV_SKIP_WHEEL_FILENAME_CHECK=1` |
| `ImportError: cannot import name 'ArgSpec'` | Python 3.11+ 移除 | 删除 `wan/multitalk.py` 第 3 行 |
| `Cannot parse precompiled_charsmap` | 缺 tokenizer.json | 见 8.2 |
| `tiktoken is required` / `protobuf not found` | 缺 tokenizer 依赖 | 装 `protobuf tiktoken` |
| `peft.helpers ... disable_input_dtype_casting` | peft 太旧 | `peft>=0.17` |
| `No module named 'num2words' / 'spacy'` | misaki 装成无 extra 版 | 装 `misaki[en]` |
| `No module named 'triton'` | xfuser 导入链需要 | 装 `triton==3.6.0` |
| `t5_int8.safetensors` 找不到 | 用了 int8 | 改用 `--quant fp8` |
| `torch.load ... require torch >= 2.6` | wav2vec2 用了 .bin | 下 safetensors 版（见 8.3） |
| 显存不足 | 分辨太高 | 加 `--num_persistent_param_in_dit 0` |

```bash

MIRROR="https://mirrors.aliyun.com/pypi/simple/"
export UV_LINK_MODE=copy

# 1. 下载厂商轮子
mkdir -p /mnt/workspace/ttv/InfiniteTalk/vendor_wheels && cd /mnt/workspace/ttv/InfiniteTalk/vendor_wheels
curl -L -o torch.whl      "$B/torch/2.10.0%2Bppu2.1.0/torch-2.10.0+cu130ubuntu2404oe-cp312-cp312-linux_x86_64.whl"
curl -L -o torchvision.whl "$B/torchvision/0.25.0%2Bppu2.1.0/torchvision-0.25.0+cu130torch2.10.0ubuntu2404ce-cp312-cp312-linux_x86_64.whl"
```
