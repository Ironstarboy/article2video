# 「只保留人像」用独立灰度遮罩做抠像，不换片段格式

需求:成片里那块**不透明的圆角卡片**会盖住幻灯片内容。用户要的是"把背景抠掉、只留人像"。

做法:给每段数字人片段**额外**生成一条灰度遮罩视频(server/matte.py,MODNet ONNX 本地推理),
叠加时 `[片段][遮罩]alphamerge` 还原带 alpha 的人像,再 `overlay` 到成片 —— 与圆角卡片
共用同一套叠加管线,只是把"几何遮罩"换成"内容遮罩"。

## Considered Options

- **换带 alpha 的中间格式(ProRes 4444 / qtrle / VP9 alpha)**:叠加最简单,但体积大 30 倍以上
  (与 ADR-0002 同一个结论),而遮罩要跟着片段长期缓存,代价不可接受。
- **在 CyberVerse 侧生成时就给纯色背景(绿幕)+ ffmpeg `colorkey`**:零模型开销、最快。
  但生成模型是"以参考图驱动"的,背景来自输入图;要它稳定输出纯绿需要改上游推理服务,
  且发丝边缘会有绿溢,模型换版本就全废。放弃。
- **换 RVM(RobustVideoMatting)**:视频原生、时序最稳,但仓库是 **GPL-3.0**,本项目不能引。
- **BiRefNet-portrait**:MIT、边缘最精细,但权重 885MB、推理慢 5–10 倍,且要多引 timm/kornia/einops。
- **MODNet(选中)**:Apache-2.0 可商用、ONNX 仅 25MB、只依赖 onnxruntime + numpy;
  真实片段实测:40.6% 像素完全透明、相邻帧 alpha 平均变化 0.0014(跳变像素 0.065%,不闪烁)、
  整张遮罩只有一个人像连通域(无碎块误检)。

## Consequences

- **人像必须贴画面下缘**:片段是齐胸特写,底边整行都是躯干(alpha≈1),人像本体横跨整个 300×300。
  摆在画面中间的角落会像"一块悬浮的半身像";贴下缘后那道平切口落在画面外沿,看上去才是站在画面下沿。
  上下角因此在抠像模式下等价(`tl≡bl`、`tr≡br`),只有左右由角落选择决定。
- **遮罩是独立文件,片段缓存不受影响**:遮罩名 = `片段名.{模型标识}{遮罩版本}.mp4`
  (`TTV_MATTE_MODEL_TAG` / `TTV_MATTE_VERSION`)。换模型或改预处理只需递增版本,
  不必重跑数字人推理;旧的圆角卡片路径完全保留。
- **alpha 必须在灰度里做全范围**:libx264 在本机 ffmpeg 4.4 上会把 `gray` 落成 `yuvj420p`(full range),
  正好是 `alphamerge` 需要的 0–255 亮度;若落成 limited range(16–235),遮罩会永远够不到 0/1、
  幻灯片上会有一层灰雾 —— 实测 luma 最小 0、最大 255,才认为这条链是通的。
- **播报视频不抠像**:那是一条独立的人像口播片,透明没有意义,保持原样输出。
- **失败一律回退圆角卡片**:抠像解释器/权重缺失、单段失败都只记日志,`avatar_error` 说明原因;
  一段遮罩没生成出来只影响那一段,不毁掉整条成片。
